# Plan: <Feature Name>

The planning templates are now divided into three complexity tiers focused on technical requirements and engineering blueprints instead of narrative user stories:

1. **Tier 1 (Small / Surgical Changes):**
   - Location: `./plan-template-tier1.md`
   - Use for: Single-file bug fixes, refactoring, minor config tweaks, small visual improvements.
2. **Tier 2 (Medium Features / Modules):**
   - Location: `./plan-template-tier2.md`
   - Use for: Multi-file features, utility functions, or non-critical migrations.
3. **Tier 3 (Complex / Critical Path):**
   - Location: `./plan-template-tier3.md`
   - Use for: Changes to payment/auth flows, database schema additions, async messaging (event buses), or third-party integrations.
