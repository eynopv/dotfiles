Reflect on current session, conversation, and user feedback. Review existing learnings, synthesize
new insights, and record updates.

Recordings must be:

- **actionable or factual**: state concrete workspace facts or actionable rules using enforcing language (**MUST**, **MUST NOT**, **DO**, **DO NOT**)
- **concise**: express the core insight in direct, simple terms without conversational padding
- **grounded**: derive strictly from verified failures, user corrections, or discovered system constraints—avoid speculative or generic textbook rules
- **generic**: abstract specific incidents into broadly applicable patterns and principles rather than isolated task minutiae
- **consolidated**: review existing recordings first; merge, update, or synthesize with related entries instead of appending duplicates
- **pruned**: actively retire, update, or remove rules that have been contradicted, superseded, or made obsolete by architectural progress
